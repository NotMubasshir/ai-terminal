What changed.

A concise history of the v1.0 direction. For implementation detail, see the repository changelog.

1.0.0

  • Security-first agent runtime and explicit state machine.
  • Structured AI provider abstraction with Gemini and mock providers.
  • Centralized tool registry/dispatcher and deterministic validation.
  • Workspace-constrained filesystem operations and safe patching.
  • Windows command, PowerShell and process infrastructure.
  • Project detection, build/test execution and Git tooling.
  • Permission modes, safe mode, resource limits and audit logging.
  • Windows CI and CPack packaging configuration.
  • Architecture, security, threat-model and development documentation.

0.2.x

The v0.2 foundation established the initial agent loop, tool system, permission manager, audit logger, workspace restrictions and structured Gemini function calling.
