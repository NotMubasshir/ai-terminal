GETTING STARTED

From clone to first task.

AI Terminal targets Windows 10/11 x64 and requires a normal C++ development environment.

Requirements

  • Windows 10/11 x64
  • Visual Studio 2022+ with Desktop development with C++
  • CMake 3.23+
  • Git
  • Gemini API key if using the Gemini provider

Build

cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --parallel

Run tests

ctest --test-dir build -C Release --output-on-failure

Run

.uildin
eleasein
eleasein
elease

Use the actual executable path produced by the current CMake configuration. The exact output directory should be checked after configuring the project rather than assumed.

First commands

AI-Terminal --help
AI-Terminal --version
AI-Terminal --safe-mode

Gemini configuration

Set GEMINI_API_KEY in the Windows user environment. AI Terminal does not write the key into its normal configuration.

[Environment]::SetEnvironmentVariable("GEMINI_API_KEY", "YOUR_API_KEY", "User")
Start in safe mode. When evaluating a new project or repository, use --safe-mode first. Inspect what the agent wants to do before granting broader permissions.
