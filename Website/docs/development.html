DEVELOPMENT

Contributing without guessing.

The project is a Windows-first C++ application. Keep changes small, testable and security-aware.

Repository map

include/       public headers
src/           implementation
include/ai     provider interfaces
include/tools  tool contracts
include/security security boundary
tests/         unit tests
docs/          architecture and security notes
.github/       Windows CI

Build discipline

  • Prefer C++20-compatible, RAII-based code.
  • Keep Windows-specific implementation isolated where practical.
  • Do not let tools bypass ToolDispatcher.
  • Add a regression test for every meaningful security or correctness bug.
  • Never log secrets or commit API keys.

Before a pull request

  1. Configure a clean build.
  2. Build Debug and Release where possible.
  3. Run CTest.
  4. Exercise security-sensitive paths.
  5. Review documentation and version references.
Windows matters. A successful Linux compile is not evidence that Windows process, filesystem or console behavior is correct.
