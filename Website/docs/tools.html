TOOL REFERENCE

The tool belt.

Every AI action enters the same dispatcher. Tools are structured, validated and risk-classified before execution.

Filesystem

ToolRiskPurpose

create_fileLOWCreate a new file
write_fileMEDIUMWrite an existing file
apply_patchMEDIUMExact-context source edit
delete_fileHIGHDestructive deletion
search_filesLOWLiteral source search

Git

ToolRiskPurpose

Risk is application-controlled. The model does not choose its own risk level and cannot bypass the dispatcher to invoke a tool directly.
