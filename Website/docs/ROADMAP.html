ROADMAP

Where it can go next.

The v1.0 foundation is intentionally conservative. Future work should improve capability without weakening the security boundary.

Near term

  • More Windows-native diagnostics and better terminal presentation.
  • Broader build/test discovery with conservative evidence requirements.
  • Stronger asynchronous cancellation around network operations.
  • More integration and security regression coverage on Windows CI.

Longer term

  • Additional AI providers behind the existing abstraction.
  • Richer project memory with explicit retention controls.
  • Optional isolated execution environments for higher-risk workflows.
Constraint: new features should not bypass the dispatcher, permission policy or execution limits.
