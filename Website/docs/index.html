What is AI Terminal?

AI Terminal is a security-first AI coding and automation terminal for Windows 10/11, written in C++20. It is designed as an agent runtime rather than a chatbot wrapped around a shell.

The rule that matters: the model is untrusted. AI Terminal owns tool registration, validation, risk classification, permissions, workspace boundaries, execution limits and audit logging.

What can it do?

  • Inspect an existing project and identify its build system.
  • Read and search source files within a controlled workspace.
  • Apply exact-context patches instead of blindly rewriting files.
  • Build with detected CMake, MSBuild or Ninja workflows.
  • Run CTest where supported and interpret real results.
  • Inspect Git state and perform permission-protected Git mutations.
  • Run bounded Windows commands and PowerShell processes.
  • Recover from build failures within configured limits.
