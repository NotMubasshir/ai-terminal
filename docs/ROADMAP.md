# Roadmap

## 1.0 implemented

The v1.0 scope is the local Windows agent runtime, security boundary, project/build/test workflow, Git integration, provider abstraction, tests and CI packaging described in the README.

## Post-1.0 candidates

- Native Windows console rendering with richer keyboard interaction.
- Better interrupt handling for in-flight network requests.
- More complete compiler/test framework adapters.
- Stronger OS-level sandboxing for untrusted repositories.
- Optional diff viewer before approval.
- Provider adapters beyond Gemini.
- More granular per-tool/per-path policies.
